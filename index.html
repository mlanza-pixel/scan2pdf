✍️
Add Text & Sign
Use a PDF you already have. No scanning required.
1

Open the document

Tap Open PDF from Files. Wait for the page preview. Use Previous/Next page to find the page to edit.

2

Add and position

Tap Add signature, Add text or Add date. Touch and drag the new item. Drag the blue handle to resize.

3

Format, save, share

Select the item to edit its words, font, size and width. Tap Save PDF or Share PDF.

🧰
PDF Tools
Merge, extract, rotate, reorder, or watermark.
1

Choose a source

Tap Open existing PDF or Use photo as PDF. Wait for the document to load.

2

Pick a tool

Choose merge, extract, rotate, reorder, delete, watermark, or page numbers. Page ranges like 1,3-5 are supported.

3

Run and review

Tap Run selected tool, then download or share the result. Use Use result for next tool for chained operations.
